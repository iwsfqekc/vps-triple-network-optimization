## 三网优化，优化的是哪三段线路

国内三家运营商各自维护一张面向境外的精品网：电信 CN2 GIA（AS4809）、联通 CUII/AS9929、移动 CMIN2（AS58807）。普通国际线路走的是 163 和 4837，高峰期拥堵、绕路、丢包都是常态。“三网优化”指的是这三家各走各的高端线路，谁也不挤在普通出口上。

普通双程 CN2 GIA 的机器只把电信那一段照顾好了，联通和移动用户晚高峰照样可能绕路。这也是为什么真正的三网优化产品定价更高，三条高端线路的带宽成本摆在那里，商家不可能白送。

香港机房的线路组合更细，大致分三类：CN2 双向（电信去回程走 CN2，联通移动走各自骨干）、CMI 直连（移动走 CMI，电信联通走 CN2 或普通线路）、三网 GIA（三家都走 GIA 级）。第三类理论上体验最好，带宽也最贵，套餐流量普遍很小。

## 怎么判断一台 VPS 是不是真三网优化

看商家写什么没用，看回程走哪个 AS 号才算数。比较可靠的办法是拿测试 IP 在自己本地网络 ping 一轮，重点看晚八点到十一点这段的表现，白天的数据说明不了问题。

LightLayer 公开记录里的测试 IP 是：Premium `128.241.250.254`、Standard `128.241.252.254`、Global `128.241.254.254`。这三个地址是早前资料记录的，如果已经变更，以官网当前页面为准。

参数之外，还有一组已经公开的路由测试可以直接参考。2026 年 7 月一份 25 分钟的三网测试跑下来，LightLayer 圣何塞到国内电信 31 个省全部连通，平均延迟 157.9ms，成功率 99.7%；移动 31 个省全部连通，平均 176.4ms，成功率 96.8%；联通只有 28 个省连通，平均 195.9ms，成功率 82.6%。回程路径是电信 CN2 GIA、移动 CMIN2、联通 4837，与前面说的完全对得上。

三个数字摆在一起，联通那栏的差距很直观。有读者在那份测试下面留了一句“湖北联通别买”，虽然只是一家之言，但和成功率 82.6% 是对得上的。同一份测试里国际方向到洛杉矶能跑到 820Mbps 上下（1Gbps 端口），说明国际出口本身不慢，问题出在联通回国的这一段。

顺带说一个容易被忽略的点：IP 信誉。同一份测试查了 439 个 DNS 黑名单，412 个干净、25 个被标记、2 个进了黑名单。整体算干净，但不是全新 IP 那种一尘不染。
